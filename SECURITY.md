# Security Policy

## Supported version

Security and privacy fixes are accepted for the latest release.

| Version | Supported |
|---|---|
| 1.x | Yes |

## Reporting

Do not open a public issue for credentials, private paths, restricted data,
personal information or exploitable workflow behavior. Use GitHub private
vulnerability reporting when available.

Include:

- affected file or workflow;
- reproduction steps;
- potential impact;
- suggested mitigation.

## Sensitive material

This repository must not contain access tokens, raw private datasets, gated
examples, model checkpoints, optimizer states or personal Google Drive paths.
